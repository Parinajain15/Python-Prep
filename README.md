# Python Prep

A hands-on Python repository built to strengthen programming fundamentals, problem-solving ability, and confidence with core Python concepts through practical implementations and small projects.

## Learning Reference

The foundational Python concepts in this repository were learned and practiced using:

**Python Programming Tutorial:**  
https://youtu.be/q3AuP01daL4

The concepts were reinforced through independent coding exercises and small programs rather than only theoretical study.

## What This Repository Covers

### Python Fundamentals
- Variables and assignment
- Built-in data types
- Type conversion
- User input and output
- Comments
- Strings and string manipulation
- Operators and expressions

### Control Flow
- Conditional statements
- `if`, `elif`, and `else`
- `for` and `while` loops
- `range()`
- `break` and `continue`
- Nested logic

### Data Structures
- Lists
- Tuples
- Sets
- Dictionaries
- Indexing and slicing
- Common collection operations

### Functions & Modules
- Defining and calling functions
- Parameters and arguments
- Return values
- Built-in functions
- Importing modules
- Using Python's `random` module

## Mini Projects

### Calculator
A command-line calculator supporting arithmetic operations with input validation and handling for invalid operations such as division by zero.

### Number Guessing Game
A simple interactive game that combines functions, loops, conditional logic, user input, and random number generation.
